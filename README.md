# 🍱 Matlådebyggare 6.0

En smart, snabb och mobilanpassad webbapp för att bygga, beräkna och hålla ordning på matlådor, storkok, frys- och skafferilager samt veckomatsedlar. 

*Speciellt anpassad för silikonformar och kubmat för ultimat frys- och portionslogistik!* (Tips på formar: [Cervera](https://www.cervera.se/varumarken/souper-cubes))

Byggd i ren **HTML, CSS och JavaScript** utan krångliga ramverk – körs direkt i webbläsaren med stöd för både svenska och engelska.

---

## ✨ Huvudfunktioner

* **Byggaren:** Skapa skiktade lådor eller "allt-i-ett"-rätter. Välj mellan standardlådor (250 ml), stora lådor (500 ml), små lådor eller såskuber. Appen räknar ut exakta makron (Kcal, Protein, Kolhydrater, Fett).
* **Inköpslista & Skafferi:** Appen drar automatiskt av det du redan har hemma i skafferiet och räknar ut exakt vad som saknas och vad det kommer att kosta i butikskassan.
* **Storkok & Mallar:** Bygg större satser, beräkna per portion, spara som favoritmallar och skicka direkt till frysen.
* **Permanenta Frys- och Skafferilager:** Håll koll på exakt hur många lådor och råvaror som finns kvar, med automatiskt uträknade utgångsdatum (3 månaders hållbarhet).
* **Veckomatsedel & Tallriksvy:** Planera veckans luncher och middagar, håll koll på proteinmålet och "ät" tallrikar för att uppdatera fryssaldot i realtid.
* **Etikettskrivare:** Generera snygga utskrivbara etiketter för dina matlådor.
* **Flerspråkigt:** Fullt stöd för svenska och engelska direkt via inställningarna.

---

## 🛠️ Teknikstack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Lagring:** `localStorage` (all data stannar lokalt på din enhet)
* **Hosting:** GitHub Pages

---

## 🚀 Kom igång (Lokal körning)

Projektet kräver ingen installation, byggprocess (build steps) eller server. 

1. Klona eller ladda ner repot.
2. Öppna `index.html` direkt i valfri modern webbläsare.
